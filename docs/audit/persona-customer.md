# 페르소나 전략 — 고객 (노던비치 40대 홈오너)

3베드 내부 + weatherboard 외부 도색 검토. "조용히 가격만" 보고 싶고 hipages식 연락 폭탄 기피. 개인정보 제공 경계.

## 여정 시뮬레이션

- 랜딩까지는 매력적 — 지역 특화 문구, Connor 실명 리뷰, 5.0★(104). 니즈("부담 없이 가격만")와 정확히 맞음.
- **첫 클릭에서 신뢰 붕괴**: "no signup fee, no obligation" 약속 후 가입+비밀번호 규칙+이메일 인증 강제 — bait 경험, 대부분 여기서 이탈.
- 통과해도 위저드가 door type × coating system, skirting linear metres 등 시공업자용 입력 요구 ("대략 얼마?"엔 과함).
- 결과 화면에서 3B2B 내부만 ~$10k, 외부 포함 시 "From AUD 35,000+" 가능 — 큰 숫자 상쇄할 맥락(리뷰·보증·근거) 부족.
- 전화번호가 앱 어디에도 없고 전환 채널이 Jobber 외부 링크 하나 — "일단 통화" 세그먼트 통째로 상실. Footer "2023"은 방치 인상.

## KPI

랜딩→견적 결과 조회률 / 폼 시작→완료율 / 결과→문의 액션(booking+tel+콜백) 통합 전환율 / 채널 믹스 / 대형 견적("35,000+") 세션 이탈률 vs 일반 세션.
